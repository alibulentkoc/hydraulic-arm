# Rover Hydraulic Arm (private)

Copyright 2026 Clemson University. All rights reserved.

This private repository holds both digital twins and all help pages.

- **Lab and tractor twin** (`twins/pick-place-twin.html`): the arm on a bench rig or a tractor. This twin is also public.
- **Rover Hydraulic Arm twin** (`twins/pick-place-twin-rover.html`): the hydraulic arm and harvest module on a rover. The design fits any rover frame. Not public.
- **Help pages** (`help/`): for both twins.

## Changes

- 2026-10-28: Renamed to the Rover Hydraulic Arm. The design is not tied to one rover brand.
- 2026-10-26: Rover Hydraulic Arm twin: the conveyor rests on a roller at the bin edge; a horizontal cylinder under the deck pushes its low end out under the gripper and pulls it back in. The stowed low end clears the row by 2 in. No track rails under the rover.

## Use the files

Open `index.html`, or open a twin file directly in a browser. No installation is necessary.
